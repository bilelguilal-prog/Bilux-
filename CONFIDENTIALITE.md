# Confidentialité Bilux V4

- App personnelle, aucune collecte serveur intégrée.
- Permissions HealthKit accordées par catégorie dans iOS : l’application lit mais n’écrit pas dans Santé.
- Stockage manuel dans le conteneur privé de l’app avec protection de fichiers après verrouillage.
- Export JSON non chiffré : ce fichier doit être stocké de façon protégée et n'est destiné ni à Netlify ni à un dépôt public.
- Les valeurs de TSH/T4L, la fatigue, la prise de médicament et les autres données de santé sont exclusivement des entrées personnelles. Elles ne déterminent ni le niveau RPG, ni la posologie.
- Usage de développement personnel ; aucun diagnostic médical.
